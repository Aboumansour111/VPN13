# MahdiVPN / VPN13

Flutter Android VPN Client + Admin and FastAPI backend.

## Repository layout
- `client/`: Flutter consumer app
- `admin/`: Flutter administrator app
- `backend/`: FastAPI + SQLAlchemy API
- `scripts/`: local build helpers
- `docs/`: architecture and setup

## Quick start
See [docs/SETUP.md](docs/SETUP.md). Build APKs locally; verify VPN operation on a real Android device with a valid node.

## Security
Never commit .env, production credentials, private VPN links, signing keys, or database dumps.
