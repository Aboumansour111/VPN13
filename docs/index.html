مبدل کانفیگ VPN13

تبدیل کانفیگ کامل Xray/V2Ray یا یک Outbound به ساختار sing-box و ساخت فایل servers.json آماده انتشار در GitHub.

این ابزار داخل مرورگر اجرا می‌شود و متن ورودی به هیچ سروری ارسال نمی‌شود. در این نسخه، پروتکل‌های Shadowsocks، VLESS، VMess، Trojan، SOCKS و HTTP از ساختار JSON پشتیبانی می‌شوند. لینک‌های اشتراکی خام و تنظیمات پیچیده/زنجیره‌ای ممکن است نیازمند تبدیل اختصاصی باشند.
