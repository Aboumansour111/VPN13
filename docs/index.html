روش استفاده

برای هر سرور یک نام نمایشی و یک کانفیگ وارد کن. می‌توانی کانفیگ‌ها را یکی‌یکی اضافه کنی. در پایان، خروجی کامل را کپی کن و محتوای فایل config/servers.json در GitHub را با آن جایگزین کن. اطلاعات فقط در همین مرورگر پردازش می‌شوند.

پشتیبانی: VLESS (TLS و Reality)، VMess، Trojan، Shadowsocks، Hysteria2، SOCKS، HTTP، خروجی sing-box و کانفیگ کامل Xray؛ پشتیبانی از VLESS XHTTP و نام قدیمی SplitHTTP با موتور Xray.
