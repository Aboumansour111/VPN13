# Xray Profile Parser

Pure Dart profile parser derived from [flutter_vless](https://github.com/XIIIFOX/flutter_vless), version 1.1.7, under the MIT license. The original copyright and license are preserved in this package.

This package contains parser/configuration code only. It has no Flutter plugin registration, Android service, native library, or VPN runtime. VPN13 uses it only to convert supported share links, Xray JSON, Clash YAML and sing-box-format JSON into Xray JSON for its single AndroidLibXrayLite Xray service.
